# ContextLift Privacy Policy

This repository holds the privacy policy for **ContextLift: Page to Markdown for AI**, a Chrome extension that turns a web page, or the part you select, into clean Markdown for pasting into an AI chat.

The policy is served by GitHub Pages at:
**https://dan-lee-odinson.github.io/contextlift-privacy/**

## In short

- ContextLift converts pages to Markdown inside your browser, only when you ask it to.
- Page content, URLs and browsing history stay on your computer.
- There are no analytics, ads or trackers, and no ContextLift server.
- If you buy Pro, ExtensionPay and Stripe handle the payment, and the extension checks with ExtensionPay whether Pro is unlocked.

The full policy is in [`index.html`](index.html).
